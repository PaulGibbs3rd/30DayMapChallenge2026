# Day 16 · Seattle, in Common

Make a Seattle transit atlas that stands on its own when shared on LinkedIn. The map tells the story of sharing a seat, a right of way, and a crossing with strangers. The page is read-only.

- **Geography.** Seattle and the nearby shoreline and ferry landings. Start with Elliott Bay, central Seattle, and Lake Washington in view.
- **Network.** Draw scheduled bus, rail, and ferry alignments from published transit data. Cite the snapshot date and identify any geographic or route selection.
- **Style.** Take the palette from Morghan Montez’s London map. Edit the vector tile stylesheet so land is saturated blue, water teal, parks lime, and roads gray. Give each transit mode a distinct color and line treatment.
- **Interaction.** Switch modes, inspect route names, and return to the opening view. All three modes appear on first load.
- **Delivery.** Keep the map in the Day 16 folder and compatible with the collection’s static GitHub Pages deployment. Store route geometry as static files. Use no visitor submissions, accounts, or feature services.
- **Verification.** Confirm the custom vector style loads, the three modes render and can be inspected, and the page works on desktop and mobile. Document data sources and style credit.
