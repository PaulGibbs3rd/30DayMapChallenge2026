Add to your AI agent

  1. Extract the ZIP and import the folders you want from skills/ using your agent’s skill installer or documented skills directory.
  2. Keep each folder’s SKILL.md and references/ together. Add the folders alongside Esri’s existing toolkit skills.
  3. Select the skill in your agent or ask for it by name, such as build-with-arcpy.

For agents without built-in skill loading, provide the Markdown and its references as task context. Running ArcGIS workflows requires the appropriate software, licenses, and access. Toolkit and setup details
