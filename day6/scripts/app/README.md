# Neon Japan source

Vite / TypeScript application for Day 6 of #30DayMapChallenge 2026.

Scaffolded with `npx @arcgis/create --name app --template js-maps-sdk-vite`.
Uses ArcGIS Maps SDK for JavaScript, Map Components, and Calcite Design System.

Run `npm ci`, then `npm run dev`. Use `npm run export` to build and export the static runtime into Day 6. The local terrain, font, and required Calcite resources are included. No API key or sign-in is required.

See the [Day 6 notes](../../readme.md) for data credits, interpretation, dependencies, and validation. The original template's optional auth example remains unused.
