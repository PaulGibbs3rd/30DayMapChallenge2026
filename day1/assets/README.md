# Day 1 artwork

The tour atlas uses the user-supplied Mountain Tour poster (`tour-poster.png`) and Superfast Jellyfish image, together with original album artwork linked from Gorillaz's official website.

The `collage/` folder contains Gorillaz/Geep, Plastic Beach, The Now Now, Demon Days and Cracker Island artwork plus `superfast-jellyfish.png`. The interface uses CSS shapes, cropping, rotation, tape and paper frames to compose these original images. Decorative images are hidden from assistive technology and do not intercept map input.

[Artwork source notes](../research/artwork-sources.md) identify the original URLs and supplied references. Gorillaz, Jamie Hewlett and the respective rights holders retain their rights to this imagery. The project is unofficial; no blanket image license is granted by the source repository.

The collection thumbnail in `directory/assets/` is a screenshot of this application and includes the same credited imagery. See the [repository credits](../../NOTICE.md).
